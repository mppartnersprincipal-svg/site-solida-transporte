Como instalar

  1. Gmail (navegador): clique em Copiar assinatura → no Gmail, ⚙️ Ver todas as configurações → Assinatura → Criar nova → cole (Ctrl+V) na caixa → defina como padrão para novos e-mails e respostas → Salvar alterações.
  2. Outlook (Windows / novo Outlook / web): Configurações → Contas → Assinaturas → nova assinatura → cole (Ctrl+V) → salvar. No Outlook clássico do Windows a logo aparece parada (ele não anima GIF); nos demais ela anima.
  3. Apple Mail (Mac): Mail → Ajustes → Assinaturas → + → desmarque "Usar sempre minha fonte padrão" → cole (Cmd+V).
  4. Celular (Gmail/Outlook app): a assinatura configurada no computador vale para o app do Gmail (mesma conta). No app do Outlook e no Mail do iPhone, cole a assinatura no campo de assinatura do app.
  5. Envie um e-mail de teste para você mesmo e confira: logo animando, links de telefone, WhatsApp, e-mail e site funcionando.
